# Wanderlust — Travel Bucket List & Global Dream Destination Milestone Tracking System

## Project files
- `index.html` — website structure and sections
- `style.css` — layout, colours, cards, responsiveness, and visual design
- `script.js` — destination filters/search, bucket list, milestone tracking, progress, budget calculator, and local storage

## How to run
1. Download and extract `Travel_Bucket_List_Assignment.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a web browser.
4. For editing, open the folder in Visual Studio Code and edit the three files.

## Features
- Responsive travel-themed landing page
- Six sample destination cards
- Filter destinations by category and search by name/country
- Add or remove destinations from a personal bucket list
- Update each saved destination's status: Want to go, Planning, Completed
- Add, complete, and delete travel milestones
- Automatic journey progress statistics
- Travel budget and savings progress calculator
- Saves the bucket list, milestones, and budget in browser `localStorage`

## Technologies
HTML5, CSS3, and JavaScript.

## Important notes
- Internet is required for the online destination photographs and Google Fonts.
- Data is stored in the current browser on the current device; this is a student demo, not a login-based cloud application.
- Sample budgets are estimates for demonstration and can be edited.
